# MATLAB parity reference

`matlab_reference.csv` is generated by MATLAB R2025b from the authoritative
MATLAB implementation. From the repository root, regenerate it with:

```sh
/Applications/MATLAB_R2025b.app/bin/matlab -batch \
  "addpath(pwd,fullfile(pwd,'tools')); generate_portable_core_reference"
```

CTest reads the same fixture as `UnitTests/TestPortableCoreParity.m`. The fixture
covers all resolved mission configurations, representative circular and
nodal-precession positions, projection and inverse-projection cases, repeating
and geodetic windows, pass boundaries, and trigger times.
