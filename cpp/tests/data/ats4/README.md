# ATS #4 MATLAB-authored runner fixtures

These source bundles are generated by
`tools/generate_ats4_portable_bundles.m` from the authoritative MATLAB
implementation. They contain typed `WVAlongTrackSchedule` and
`WVAlongTrackObservingSystem` construction records, an empty future-output
axis, and one complete coefficient-restart stream. The companion requests use
paths relative to this directory so a copied fixture is portable.

The process-level acceptance test snapshots both each committed source and
its private working copy before execution, then verifies those byte arrays
after base-runner rejection, create, failed create, failed replacement,
successful replacement, append/restart, and the continuous control. The
destination state sequence is absent before create; a complete NetCDF output
after create; byte-identical after failed create and failed replacement; an
explicit `ATS4 prior destination N` sentinel before successful replacement;
and a valid, non-sentinel NetCDF output after atomic installation. Append then
advances each destination ordinal and record count by the same amount, while
the independently persisted schedule continuation is compared separately.

The fixture generator intentionally makes the repeating/fixed event an exact
step endpoint and the nonrepeating geodetic/adaptive event a dense-output
time. It requests `ssh`, `ssu`, and `ssv` in both cases. No output or report
created by a test run belongs in this directory.

Matched performance reports and their frozen environment are under
`benchmark/`.
